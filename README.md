# أبطال كالمي — بدون Vercel ولا Firebase

**الفكرة:** صفحة الآيباد على GitHub Pages (مجانًا من حسابك الحالي)، وصفحة الشاشة تفتحها من اللابتوب مباشرة كملف. الصورة تنتقل من الآيباد إلى الشاشة مباشرة (اتصال مباشر بين الجهازين)، فلا تُخزَّن على أي موقع ولا تنرفع وجوه الأطفال للإنترنت.

## 1) صفحة الآيباد على GitHub Pages
1. في GitHub: ➕ ← **New repository** ← الاسم `calmi-space` ← **Public** (ضروري لـ Pages المجاني، وما فيه أي صور أطفال) ← Create.
2. اضغط **uploading an existing file** وارفع الملف `index.html` فقط من مجلد upload_to_github ← Commit.
3. Settings ← **Pages** ← Source: Deploy from a branch ← Branch: main و / (root) ← Save. بعد دقيقة يظهر رابط مثل `https://اسمك.github.io/calmi-space/`.

## 2) الكلمة السرية
اختر كلمة عشوائية (حروف إنجليزية وأرقام وشرطة، 6 أحرف أو أكثر) مثل `hail-k7x9q2m4w8`.
- رابط الآيباد: `https://اسمك.github.io/calmi-space/#hail-k7x9q2m4w8` (احفظه في الشاشة الرئيسية للآيباد).

## 3) الشاشة
1. افتح الملف `screen.html` من مجلد screen بمتصفح Chrome (نقرتين).
2. اكتب نفس الكلمة السرية في المربع (تنحفظ بعدها). اضغط F لملء الشاشة. النقطة أسفل اليسار **خضراء** = جاهزة.
3. لا تقفل هذه الصفحة طول الفعالية. لو انقفلت بالغلط افتحها وترجع كل الصور والعدّاد.

## يوم الفعالية
- الأفضل يكون الآيباد واللابتوب على **نفس الواي فاي أو الهوت سبوت**، ولازم إنترنت.
- الكليكر: أي زر يبدّل بين الشاشة وشاشة الختام. وفي شاشة الختام زر **Delete** يحذف كل الصور والعداد (بعد تأكيد).
- الصور محفوظة داخل متصفح اللابتوب فقط.

## ملاحظات
- الربط المباشر يعتمد على خادم مجاني عام للتعارف بين الجهازين (PeerJS). جرّب كامل المسار على شبكة الفعالية قبل اليوم.
- ثبّت الآيباد على صفحة الإرسال وفعّل Guided Access وأطفئ القفل التلقائي.
